任务一 · 提示词工程师

目标：让 AI 听懂需求，生成 new Swiper('#wySw4', {...}) 配置 —— ① 无缝循环 ② 3.2 秒自动翻页且手动操作后不停止 ③ 圆点分页器可点击 ④ 初始效果 cube。共两轮迭代，每轮保留提示词与 AI 回答。

第 1 轮：第一版提示词（有遗漏）

我发出的提示词：

帮我用 Swiper 6 写一个轮播配置：容器是 #wySw4，要能无缝循环播放，每 3.2 秒自动翻一次页，底下要有圆点分页器，切换效果用 cube 立方体。

AI 的回答（代码）：

new Swiper('#wySw4', {
  loop: true,                        // 无缝循环 ✓
  autoplay: { delay: 3200 },         // 自动翻页 ✓（但漏了不停止的要求）
  pagination: { el: '#wyPag4' },     // 圆点 ✓（但不可点击）
  effect: 'cube',                    // 立方体 ✓
});

亲手粘进页面验证发现的问题：

① 手动拖动或点圆点后，轮播就永远停了——AI 没写 disableOnInteraction: false；② 圆点点了没反应——AI 没写 clickable: true；③ 没写 speed，翻页瞬间完成，看不出 cube 的旋转过程。

第 2 轮：说清楚需求后的修正版

我发出的提示词（把验收标准逐条写进提示词）：

上一版有三个问题。请严格按这四条验收标准重新给 Swiper 6 的 #wySw4 配置：① loop 无缝循环，最后一张往后翻直接回到第一张；② autoplay delay 3200，且必须加 disableOnInteraction: false——人拖动、点圆点之后也要继续自动翻；③ 分页器圆点必须 clickable: true，点第几个圆点跳第几张；④ effect: 'cube' 初始就是立方体，speed 给 800 让旋转看得清。请逐条对照，一条都不能少。

AI 的回答（代码）：

new Swiper('#wySw4', {
  effect: 'cube',                    // ④ 初始立方体 ✓
  speed: 800,                        // 翻页动画 800ms，旋转看得清 ✓
  loop: true,                        // ① 无缝循环 ✓
  autoplay: {
    delay: 3200,                     // ② 每 3.2 秒自动翻页 ✓
    disableOnInteraction: false,     // ② 手动操作后继续自动翻 ✓
  },
  pagination: {
    el: '#wyPag4',
    clickable: true,                 // ③ 圆点可点击跳转 ✓
  },
  grabCursor: true,                  // 手型光标，提示可拖动（附加）
});

逐条验证结论（截图见下方占位）：

验收项验证方式结论
① 无缝循环翻到最后一张继续向后拖直接回到第一张，无回跳空隙，通过
② 自动翻页不停止先拖动一次再静置观察松手后 3.2 秒照样继续翻，通过
③ 圆点可点击点击第 3 个圆点立即跳到第 3 张，通过
④ 初始 cube刷新页面看第一屏开场即 3D 立方体旋转切换，通过
一句话结论：第 2 轮提示词把"验收标准"逐条写进需求后，AI 一次给出了完全合格的配置。

答辩抽问 · 自答

问：你的第一版提示词漏掉了哪个需求？
答：漏了"手动操作后不停止"和"圆点可点击"这两条行为细节。第一版只描述了"有什么"（圆点、自动翻），没描述"怎么表现"（点了要有反应、拖完要继续翻）。

问：你是怎么在第二轮里"说清楚"的？
答：把模糊的形容词换成可验证的参数名——"不停止"写成 disableOnInteraction: false，"圆点能点"写成 clickable: true，并声明"逐条对照、一条不能少"，让 AI 按验收清单自检。

问：AI 第一次给的代码错在哪？
答：不是语法错，是行为错——autoplay 缺 disableOnInteraction: false（Swiper 默认交互后停止）、pagination 缺 clickable: true（默认只作指示不可点）、没配 speed 导致 cube 动画几乎看不见。语法正确的代码也会"不听话"，需求必须精确到参数。
