任务二 · creative 仿写

课堂讲了 6 种 effect，第 7 种 creative（自定义变换）靠 AI 自学 + 官方示例 257-effect-creative.html 读懂 creativeEffect 的 transform 写法，为演示四新增「creative 电影墙」按钮。

第一步 · 跟着 AI 读官方示例

我发给 AI 的问题：「Swiper 官方示例 swiper/demo/257-effect-creative.html 里 creativeEffect 的 prev / next 中的 translate、rotate、scale、opacity 分别怎么写？数组的三个数字各是什么意思？」

AI 拆解出的写法要点：

creativeEffect: {
  limitProgress: 2,        // 相邻几张还参与变换（2 = 前后各一张）
  prev: {                  // "上一张"离开时的样子
    translate: ["-120%", 0, -240],  // 数组 = [X, Y, Z]
    rotate: [0, 0, -8],             // 数组 = [绕X轴, 绕Y轴, 绕Z轴]，单位度
    opacity: 0.3,
    scale: 0.85,
  },
  next: { ... },           // "下一张"进场的样子，写法相同
}

第二步 · 电影墙参数（已写入 swiper-task.html 第 7 个按钮）

效果要求：上一张缩小、左移并带角度，下一张放大、右移进场——像在电影选片墙上推拉海报：

prev: { translate: ["-120%", 0, -240], rotate: [0, 0, -8], opacity: 0.3, scale: 0.85 },
next: { translate: ["120%", 0, -120],  rotate: [0, 0,  8], opacity: 0.5, scale: 1.15 },
验证结论：点「creative 电影墙」按钮，离场卡片缩小左偏 8 度、进场卡片从右侧放大推近，自动翻页与圆点均正常（本地 Swiper 6.8.4 自动化实测通过，截图见下方占位）。
📸 截图占位：请粘贴 swiper-task.html 中点「creative 电影墙」后的切换瞬间截图（能看出左右两卡的倾斜与缩放）。

追问 · 用自己的话回答

向 AI 追问：prev / next 的 transform 各控制什么？

我的理解：prev 描述的是正在离开的这一张从当前位置变成什么样子——它往哪挪、缩多小、转多少度、透明到什么程度；next 描述的是还没登场的下一张从哪个角落、以什么姿态进入画面。两者合起来就是"一退一进"的整场戏：prev 管"怎么退场"，next 管"怎么登场"。

答辩抽问 · 自答

问：transform 里的百分号是相对谁的？
答：相对slide 自身的尺寸——X 方向的百分号按幻灯片的宽度算，Y 方向按高度算。"120%" 就是把自己整个宽度再多挪出去一点，保证完全离开可视区。

问：改一个数值让卡片转 20 度试试？
答：把 prev / next 的 rotate 第三个数字从 ±8 改成 ±20：

prev: { ..., rotate: [0, 0, -20] },
next: { ..., rotate: [0, 0,  20] },
实验结论：卡片入场 / 离场的倾斜明显变陡，像把海报在墙上甩了一个更大的角度；其余参数不变，翻页、自动播放不受影响（本地实测 rotateZ ±8 → ±20 生效）。
📸 截图占位：请粘贴 rotate 改为 ±20 后的切换瞬间截图，与 8 度版本对比。
