实现 · creative「电影墙」切换效果

仿官方示例 257 的 creativeEffect 配置：上一张缩小、左移并带角度退场，下一张放大、从右侧进场，一退一进合成"电影墙"。

creativeEffect: {
  limitProgress: 2,           // 上下各保留 2 张参与演出
  prev: { translate: ["-120%", 0, -240], rotate: [0, 0, -8], opacity: 0.3, scale: 0.85 },  // 缩小·左移·带角度离场
  next: { translate: ["120%", 0, -120],  rotate: [0, 0,  8], opacity: 0.5, scale: 1.15 },  // 放大·右移进场
}

简短解说

prev 是正在离开的一张（往左缩小倾斜退场），next 是还没登场的下一张（从右侧放大压进）；translate 的百分号相对 slide 自身尺寸，任何屏幕宽度下位移比例一致。

对照实验 · rotate 从 ±8° 改成 ±20°

只把两个 rotate 的第三个数字从 ±8 改为 ±20，其余参数完全相同——实测倾斜明显变陡，位移、缩放、透明度不受影响，证实第三个数字就是绕 Z 轴的平面旋转角。
