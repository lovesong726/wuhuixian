简短解说

核心配置：direction: 'vertical' 把轮播从左右切换改为上下切换，mousewheel: { invert: false, forceToAxis: false, releaseOnEdges: false } 让滚轮方向与竖向翻页自然对应，再配合 loop 无缝循环与 autoplay 3.2 秒自动翻页。

AI 翻车实录：AI 曾建议 releaseOnEdges: true 防止滚轮"劫持页面"，但 Swiper 6.8.4 源码 mousewheel.js 第 382~386 行显示该逻辑被 !swiper.params.loop 短路——循环模式下此参数无效。故显式写 false 并注释原因；实测移开光标后页面滚轮立刻恢复，无需依赖该参数。
